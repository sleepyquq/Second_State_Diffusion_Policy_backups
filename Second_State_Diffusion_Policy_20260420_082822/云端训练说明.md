# Windows 云主机训练说明

本文档用于把本项目上传到 **Windows CUDA 云主机** 后，快速完成环境检查、最小验证、数据收集和 Diffusion Policy 训练。

## 一、推荐 Windows 云主机配置

优先选择 NVIDIA CUDA GPU：

| 用途 | 推荐 GPU | 说明 |
|------|----------|------|
| State 模式最小验证 | T4 / 3060 / 4060 起步 | 可跑通代码链路，但训练较慢 |
| State 模式正式训练 | RTX 3090 / 4090 / A10 | 推荐 16GB 以上显存 |
| RGBD 视觉训练 | RTX 3090 / 4090 / A10 / A100 | 推荐 24GB 显存 |

本阶段建议先做 `PickCube-v1 + state`，等训练闭环稳定后再迁移 RGBD。

## 二、上传项目

推荐用 Git：

```bash
git clone <你的仓库地址>
cd Second_State_Diffusion_Policy
```

如果暂时不用 Git，也可以把整个文件夹上传到云主机，然后进入项目目录。

## 三、创建环境

建议使用 Python 3.10 或 3.11。ManiSkill 官方更推荐 3.9-3.12，训练环境不要用本地已有的异常 Python。

在 PowerShell 中执行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

如果 PowerShell 禁止激活脚本：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

安装 CUDA 版 PyTorch。下面以 CUDA 12.1 为例，若云主机镜像是 CUDA 11.8，可把 `cu121` 改为 `cu118`。

```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements_cloud.txt
```

## 四、环境确认

先确认 Python、CUDA、ManiSkill 都可用：

```powershell
python --version
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'no cuda')"
python -c "import gymnasium, mani_skill; print(gymnasium.__version__); print(mani_skill.__version__)"
nvidia-smi
```

必须看到 `torch.cuda.is_available()` 输出 `True`，否则不建议正式训练。

## 五、第一阶段最小验证

先验证环境可以创建并 step：

```powershell
python -m py_compile run_tasks.py collect_demos.py train_dp.py
python run_tasks.py --worker PickCube-v1 state 1 2
python run_tasks.py --worker PegInsertionSide-v1 state 1 2
```

如果 state 模式通过，再考虑 RGBD：

```powershell
python run_tasks.py --worker PickCube-v1 rgbd 1 2
```

RGBD 首次运行可能会下载资产并初始化渲染，时间会更长。

## 六、专家数据 smoke test

先只收集 3 条成功轨迹，确认专家策略可用：

```powershell
python collect_demos.py --env PickCube-v1 --obs-mode state --n-demos 3 --max-steps 500 --output demos_PickCube-v1_state_smoke.h5
python collect_demos.py --info --dataset demos_PickCube-v1_state_smoke.h5
```

注意观察日志中是否出现：

```text
[专家策略] 使用 PickCube 内置运动规划专家
```

如果出现“内置专家不可用，使用随机动作”，这批数据不能用于训练，需要先修专家策略导入路径。

## 七、训练 smoke test

先用极小数据跑 1 轮，目标是确认训练、评估、保存 checkpoint 不崩：

```powershell
python train_dp.py \
  --data demos_PickCube-v1_state_smoke.h5 \
  --env PickCube-v1 \
  --obs-mode state \
  --epochs 1 \
  --batch-size 16 \
  --eval-every 1 \
  --eval-episodes 1 \
  --output-dir output_smoke
```

PowerShell 单行版：

```powershell
python train_dp.py --data demos_PickCube-v1_state_smoke.h5 --env PickCube-v1 --obs-mode state --epochs 1 --batch-size 16 --eval-every 1 --eval-episodes 1 --output-dir output_smoke
```

成功后应看到 `output_smoke/checkpoints/policy_best.pt`。

## 八、PickCube State 正式训练

收集 100 条演示：

```powershell
python collect_demos.py \
  --env PickCube-v1 \
  --obs-mode state \
  --n-demos 100 \
  --max-steps 500 \
  --output demos_PickCube-v1_state_100.h5
```

训练：

```powershell
New-Item -ItemType Directory -Force logs
python train_dp.py \
  --data demos_PickCube-v1_state_100.h5 \
  --env PickCube-v1 \
  --obs-mode state \
  --epochs 100 \
  --batch-size 256 \
  --lr 1e-4 \
  --weight-decay 1e-6 \
  --ema-decay 0.9999 \
  --eval-every 5 \
  --eval-episodes 10 \
  --output-dir output_pickcube_state \
  *> logs\pickcube_state_train.log
```

PowerShell 单行版：

```powershell
New-Item -ItemType Directory -Force logs
python train_dp.py --data demos_PickCube-v1_state_100.h5 --env PickCube-v1 --obs-mode state --epochs 100 --batch-size 256 --lr 1e-4 --weight-decay 1e-6 --ema-decay 0.9999 --eval-every 5 --eval-episodes 10 --output-dir output_pickcube_state *> logs\pickcube_state_train.log
```

## 九、PegInsertionSide State 验证

插入任务更难，先用 state 模式建立基线：

```powershell
python collect_demos.py \
  --env PegInsertionSide-v1 \
  --obs-mode state \
  --n-demos 100 \
  --max-steps 800 \
  --output demos_PegInsertionSide-v1_state_100.h5

python train_dp.py \
  --data demos_PegInsertionSide-v1_state_100.h5 \
  --env PegInsertionSide-v1 \
  --obs-mode state \
  --epochs 100 \
  --batch-size 256 \
  --lr 1e-4 \
  --eval-every 5 \
  --eval-episodes 10 \
  --output-dir output_peg_state
```

`train_dp.py` 会根据数据自动推断 state 观测维度；也可以显式传 `--obs-dim 43`。

## 十、和 Codex 协作

建议把云端训练输出保存到 `logs/`，每次出现报错或指标异常，把以下内容发回：

1. 运行命令
2. 完整报错或最后 80 行日志
3. `python -c "import torch; print(torch.__version__, torch.cuda.is_available())"` 输出
4. 生成的数据文件名和 checkpoint 路径

如果使用 Git，同步流程为：

```powershell
git pull
# 跑训练或验证
git status
```

本地修改代码后再推送，云端 `git pull` 即可继续。
